# MyContacts

**MyContacts** — это минималистичное веб-приложение для создания персональной страницы с контактами и ссылками.  
Одна ссылка — все ваши соцсети, мессенджеры и способы связи.

---

## Возможности

-  Создание неограниченного количества карточек с ссылками
-  Редактирование названия и URL карточек
-  Удаление карточек
-  Иконки и кастомные цвета для каждой ссылки
-  Публичная страница для шаринга
-  Локальное сохранение данных (LocalStorage)
-  Адаптивный дизайн (mobile / desktop)
-  Страница авторизации (в процессе)

## 🚧 Статус проекта

Проект находится на стадии **MVP / DEMO**.

Функционал может изменяться, дополняться или перерабатываться.  
Некоторые возможности находятся в разработке или планируются к реализации в будущих версиях.

Проект создаётся как пет-проект и платформа для дальнейшего развития.

## Запуск проекта

Убедитесь, что у вас установлен **Yarn**.

```bash
yarn install
yarn dev
```
